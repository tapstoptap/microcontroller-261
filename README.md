# microcontroller-261
This repo contains the materials done during lab sessions of course CO3010 - Semester 261.

# Project folders

- `Proteus_Project/`: Proteus circuit projects and supporting images.
- `workspace_1.7.0/`: STM32CubeIDE 1.7.0 projects, including source code, project settings, device configuration, and required drivers.

IDE workspace metadata, compiled `Debug`/`Release` output, and Proteus backups are excluded. Open or import individual projects from `workspace_1.7.0/` in STM32CubeIDE.
